## Current environment

Zellij:

    0.45.0

Rust WASM target:

    wasm32-wasip1

## Contents

- `config.kdl` — live Zellij configuration
- `layouts/post-apollo.kdl` — Post-Apollo layout
- `post-apollo/plugin/` — custom Post-Apollo Zellij plugin source
- `post-apollo/plugin/post-apollo.kdl` — plugin-related configuration

## Upstream provenance

The root `config.kdl` was generated by Zellij and then customized for Post-Apollo. The custom Rust plugin is original Post-Apollo implementation built against Zellij's plugin API.

See [THIRD_PARTY_NOTICE.md](./THIRD_PARTY_NOTICE.md) for the exact boundary and upstream MIT attribution.
